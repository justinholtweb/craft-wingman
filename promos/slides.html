Templates

Twig or Blade,
same query

Model columns read like element properties.

  • Elements print their label column
  • From a model row to its element
{# Twig #} {% for customer in craft.customers().orderBy('name').all() %} {{ customer }} — {{ customer.company }} {% endfor %} {% set element = wingman.element(order.customer) %} {{-- Blade --}} @foreach ($craft->customers()->all() as $customer) {{ $customer }} — {{ $customer->company }} @endforeach
